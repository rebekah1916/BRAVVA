# BRAVVA · Dashboard de Proyecto

Portal de recursos de marca BRAVVA (HTML, CSS y JS puro).

## Estructura
```
index.html        → el portal
descargas/        → archivos que se descargan desde cada botón
vercel.json       → fuerza la descarga de los archivos en todos los dispositivos
```

## Actualizar un recurso
Reemplaza el archivo dentro de `descargas/` manteniendo **el mismo nombre**, haz commit y Vercel se actualiza solo.
